# Data licensing

The MIT license in `LICENSE-CODE` applies only to original OVERSEER application
code and original project documentation. It does not relicense imported lore,
facts, quotations, source metadata, generated lore databases, or third-party
contributions. Those materials remain subject to their own source licenses,
terms, provenance, and attribution requirements.

The Phase 1 sample importer obtains revision metadata from the Independent
Fallout Wiki. The API's live `rightsinfo` response on 2026-09-16 identified its
text license as **Creative Commons Attribution-ShareAlike 4.0**. The returned
rights URL was malformed; the exact response is retained by each successful
probe. Users must review the current source terms before distributing a built
database. A future change in source rights must not be inferred to relicense
older revisions.

The fixture manifest contains short, original summaries and structured facts,
not copied articles. Each imported record retains its source page, revision,
retrieval time, license response, and continuity classification.
